# CARLA-site

Site minimal destiné à afficher le portfolio de Carla avec une URL fixe.

## Mettre à jour le portfolio sans changer le QR code

1. Remplacer le fichier `portfolio.pdf` par la nouvelle version.
2. Conserver exactement le même nom : `portfolio.pdf`.
3. Ne pas changer l'URL du site / du QR code.

Le QR code pointe vers la page du site, qui charge toujours le fichier `portfolio.pdf`.
